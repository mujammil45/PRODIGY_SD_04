# PRODIGY_SD_04 – Sudoku Solver

## 📌 Project Description
This project is a Sudoku Solver developed using Python as part of the Prodigy InfoTech Software Development Internship Program.

The program automatically solves an unsolved Sudoku puzzle using the **Backtracking Algorithm**.

## 🚀 Features
- Solves 9×9 Sudoku puzzles automatically.
- Uses the Backtracking Algorithm.
- Checks rows, columns, and 3×3 boxes.
- Displays the original and solved Sudoku grids.
- Detects puzzles with no valid solution.

## 🛠️ Technologies Used
- Python 3
- Backtracking Algorithm

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python sudoku_solver.py
```

## 🧠 Algorithm
The program uses Backtracking:
1. Finds an empty cell (represented by 0).
2. Tries numbers from 1 to 9.
3. Checks whether the number is valid.
4. If valid, places the number and continues.
5. If no number works, it goes back and tries another possibility.
